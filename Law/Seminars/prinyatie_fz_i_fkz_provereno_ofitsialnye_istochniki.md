# Принятие федерального закона (ФЗ) и федерального конституционного закона (ФКЗ) в Российской Федерации

> **Проверенная редакция:** 21 сентября 2026 года.  
> **Статус:** учебно-справочная схема общего законодательного процесса, перепроверенная по официальным источникам: Конституции РФ, Регламенту Государственной Думы, Регламенту Совета Федерации и Федеральному закону от 14.06.1994 № 5‑ФЗ.  
> **Граница схемы:** это общий порядок. Для бюджета, международных договоров, законов о поправке к Конституции и иных специальных видов актов предусмотрены дополнительные или специальные процедуры.

---

## 1. Ключевое различие ФЗ и ФКЗ

| Параметр | ФЗ — федеральный закон | ФКЗ — федеральный конституционный закон |
|---|---|---|
| **Когда принимается** | По вопросам, относящимся к федеральному законодательному регулированию в рамках Конституции РФ | Только по вопросам, по которым Конституция РФ прямо предусматривает принятие федерального конституционного закона |
| **Рассмотрение в ГД** | Обычно три чтения; возможны исключения, предусмотренные законом и Регламентом ГД | Обычно три чтения; возможны исключения, предусмотренные законом и Регламентом ГД |
| **Итоговое голосование в ГД** | Более половины голосов от общего числа депутатов Государственной Думы: **не менее 226 из 450** | Не менее двух третей голосов от общего числа депутатов Государственной Думы: **не менее 300 из 450** |
| **Рассмотрение в СФ** | СФ может одобрить закон голосованием; для ФЗ, не перечисленных в ст. 106 Конституции, действует также правило об одобрении при нерассмотрении в течение 14 дней | Необходимо активное одобрение СФ; одобрение «по молчанию» не применяется |
| **Порог в СФ** | Более половины от общего числа сенаторов РФ | Не менее трех четвертей от общего числа сенаторов РФ |
| **Если СФ отклонил** | Палаты могут создать согласительную комиссию; ГД вправе повторно принять прежнюю редакцию большинством не менее 2/3 от общего числа депутатов | Требуемое одобрение СФ не может быть заменено повторным голосованием одной ГД; ст. 108 Конституции требует одобрения обеими палатами в установленных квалифицированных пропорциях |
| **Президент** | Подписывает и обнародует в течение 14 дней либо отклоняет закон | Принятый в конституционном порядке ФКЗ подлежит подписанию и обнародованию Президентом в течение 14 дней; ст. 108 Конституции не устанавливает процедуру отклонения ФКЗ, аналогичную ст. 107 для ФЗ |

**Конституционная основа:** статьи 104–108 Конституции РФ. Статья 108 регулирует ФКЗ; статьи 105–107 — ФЗ.

## 2. Полная древовидная схема

```text
НАЧАЛО: законодательная инициатива
│
├─ 1. Субъекты права законодательной инициативы (ч. 1 ст. 104 Конституции РФ)
│  ├─ Президент РФ
│  ├─ Совет Федерации
│  ├─ сенаторы РФ
│  ├─ депутаты Государственной Думы
│  ├─ Правительство РФ
│  ├─ законодательные (представительные) органы субъектов РФ
│  └─ Конституционный Суд РФ и Верховный Суд РФ — только по вопросам их ведения
│
├─ 2. Подготовка и внесение законопроекта в Государственную Думу
│  ├─ Определяется вид акта: ФЗ или ФКЗ
│  ├─ Законопроект направляется на имя Председателя ГД
│  ├─ К нему прилагаются, в частности:
│  │  ├─ пояснительная записка;
│  │  ├─ текст проекта с указанием инициатора;
│  │  ├─ перечень актов, которые потребуется изменить, приостановить,
│  │  │  отменить, признать утратившими силу или принять;
│  │  ├─ финансово-экономическое обоснование, если реализация потребует затрат;
│  │  ├─ заключение Правительства РФ — для проектов из ч. 3 ст. 104 Конституции;
│  │  └─ специальные документы для отдельных видов законопроектов.
│  ├─ Проекты из ч. 3 ст. 104 Конституции РФ могут быть внесены
│  │  только при наличии заключения Правительства РФ
│  └─ Регистрация в аппарате ГД → регистрационный номер → электронная карта
│
├─ 3. Предварительное рассмотрение в Государственной Думе
│  ├─ Председатель ГД направляет проект в профильный комитет
│  ├─ Профильный комитет проверяет соответствие ст. 104 Конституции РФ
│  │  и требованиям Регламента ГД
│  │  ├─ Требования соблюдены
│  │  │  └─ Совет ГД назначает ответственный комитет,
│  │  │     при необходимости — комитеты-соисполнители;
│  │  │     направляет материалы в комитеты, комиссии, фракции и иным адресатам;
│  │  │     устанавливает сроки отзывов и подготовки к I чтению.
│  │  └─ Требования не соблюдены
│  │     └─ Проект возвращается инициатору для выполнения требований;
│  │        проект не считается внесенным в ГД.
│  ├─ Если отсутствует заключение Правительства там, где оно обязательно,
│  │  профильный комитет учитывает мнение Правового управления аппарата ГД
│  ├─ Проект ФЗ по предметам совместного ведения РФ и субъектов РФ
│  │  └─ направляется законодательным органам и высшим должностным лицам субъектов РФ
│  │     для отзывов.
│  └─ Подготовка ответственным комитетом
│     ├─ отзывы, предложения, замечания;
│     ├─ рабочая группа и экспертизы — при необходимости;
│     ├─ правовая и юридико-техническая экспертизы;
│     ├─ лингвистическая экспертиза — по поручению;
│     └─ заключение комитета и проект постановления ГД.
│
├─ 4. Рассмотрение в Государственной Думе
│  │
│  ├─ Общее правило: три чтения
│  │
│  ├─ I чтение — концепция законопроекта
│  │  ├─ Обсуждаются концепция, актуальность, практическая значимость,
│  │  │  соответствие базовых положений Конституции РФ
│  │  ├─ Возможные решения ГД:
│  │  │  ├─ отклонить законопроект → КОНЕЦ;
│  │  │  ├─ принять ФЗ / одобрить ФКЗ в I чтении → этап поправок;
│  │  │  └─ принять ФЗ / одобрить ФКЗ сразу, минуя II и III чтения,
│  │  │     если соблюдены условия Регламента ГД;
│  │  │     для проектов по предметам совместного ведения этот ускоренный путь исключен.
│  │  └─ Постановлением ГД устанавливается срок подачи поправок
│  │
│  ├─ Подготовка ко II чтению
│  │  ├─ Поправки вправе вносить субъекты законодательной инициативы
│  │  ├─ Ответственный комитет обобщает и рассматривает поправки
│  │  ├─ Формируются таблицы поправок: рекомендованных к принятию,
│  │  │  к отклонению, без решения, а также при необходимости меняющих концепцию
│  │  └─ Проводится постатейная правовая и лингвистическая экспертиза
│  │
│  ├─ II чтение — детальная доработка
│  │  ├─ Рассматриваются таблицы и отдельные поправки, текст с поправками
│  │  ├─ Возможные результаты:
│  │  │  ├─ принятие/одобрение во II чтении → III чтение;
│  │  │  ├─ продолжение работы над проектом в предусмотренных Регламентом формах;
│  │  │  └─ отклонение проекта → КОНЕЦ.
│  │  └─ После II чтения текст направляется на лингвистическую экспертизу;
│  │     допустимы редакционные и юридико-технические уточнения в порядке Регламента
│  │
│  └─ III чтение — окончательное голосование
│     ├─ Голосуется законопроект в целом
│     ├─ ФЗ: требуется более половины голосов от общего числа депутатов ГД (≥226)
│     │  ├─ набрано → ФЗ принят ГД
│     │  └─ не набрано → ФЗ не принят
│     └─ ФКЗ: требуется не менее 2/3 от общего числа депутатов ГД (≥300)
│        ├─ набрано → ФКЗ одобрен ГД
│        └─ не набрано → ФКЗ не одобрен ГД
│
├─ 5. Передача закона из ГД в СФ
│  ├─ Принятый ФЗ передается в Совет Федерации в течение 5 дней
│  └─ Одобренный ГД ФКЗ также передается для рассмотрения СФ
│
├─ 6. Рассмотрение в Совете Федерации
│  │
│  ├─ Ветвь А: ФЗ
│  │  ├─ Регистрация: в течение 1 часа; рассылка сенаторам — не позднее 24 часов
│  │  ├─ Председатель СФ определяет ответственный комитет и направляет закон
│  │  │  в него и в Правовое управление аппарата СФ — не позднее 24 часов
│  │  ├─ Срок комитетской подготовки заключения — как правило, не менее 72 часов
│  │  ├─ Обязательному рассмотрению СФ подлежат ФЗ по вопросам (ст. 106 Конституции):
│  │  │  ├─ федерального бюджета;
│  │  │  ├─ федеральных налогов и сборов;
│  │  │  ├─ финансового, валютного, кредитного, таможенного регулирования,
│  │  │  │  денежной эмиссии;
│  │  │  ├─ ратификации и денонсации международных договоров РФ;
│  │  │  ├─ статуса и защиты государственной границы РФ;
│  │  │  └─ войны и мира.
│  │  ├─ ФЗ, не подпадающий под ст. 106 Конституции:
│  │  │  ├─ СФ одобрил: более половины от общего числа сенаторов → Президенту;
│  │  │  ├─ СФ отклонил → разногласия с ГД;
│  │  │  └─ СФ не рассмотрел в течение 14 дней → ФЗ считается одобренным → Президенту.
│  │  └─ ФЗ из ст. 106 Конституции:
│  │     ├─ обязательное рассмотрение СФ;
│  │     ├─ автоматического одобрения по истечении 14 дней нет;
│  │     ├─ одобрение: более половины от общего числа сенаторов → Президенту;
│  │     └─ отклонение → разногласия с ГД.
│  │
│  └─ Ветвь Б: ФКЗ
│     ├─ Требуется активное одобрение СФ
│     ├─ «За» должно быть не менее 3/4 от общего числа сенаторов РФ
│     ├─ Правило о 14 днях и одобрении «по молчанию» не действует
│     ├─ При одобрении нужным большинством ФКЗ считается принятым → Президенту
│     └─ При отсутствии требуемого большинства ФКЗ не принят
│
├─ 7. Разногласия ГД и СФ по ФЗ
│  ├─ СФ отклоняет ФЗ → закон возвращается в ГД
│  ├─ ГД может:
│  │  ├─ снять закон с дальнейшего рассмотрения;
│  │  ├─ создать с согласия/по предложению СФ согласительную комиссию;
│  │  └─ принять закон в ранее принятой ГД редакции.
│  ├─ Согласительная комиссия вырабатывает единый текст
│  ├─ Если ГД принимает согласованный текст простым большинством → он направляется в СФ
│  └─ Если ГД принимает прежнюю редакцию вопреки СФ
│     ├─ необходимо не менее 2/3 от общего числа депутатов ГД (≥300)
│     └─ Председатель ГД направляет повторно принятый ФЗ Президенту в течение 5 дней
│
├─ 8. Президент РФ
│  │
│  ├─ ФЗ
│  │  ├─ Принятый ФЗ поступает Президенту
│  │  ├─ В течение 14 дней Президент:
│  │  │  ├─ подписывает и обнародует ФЗ; либо
│  │  │  └─ отклоняет ФЗ → повторное рассмотрение ГД и СФ.
│  │  ├─ При повторном рассмотрении возможны согласие с вето,
│  │  │  редакция Президента, специальная комиссия или сохранение прежней редакции
│  │  └─ Если прежняя редакция снова одобрена:
│  │     ├─ не менее 2/3 от общего числа депутатов ГД; и
│  │     ├─ не менее 2/3 от общего числа сенаторов СФ,
│  │     └─ Президент подписывает и обнародует закон в течение 7 дней.
│  │
│  └─ ФКЗ
│     ├─ ФКЗ, принятый палатами в порядке ч. 2 ст. 108 Конституции РФ,
│     │  подлежит подписанию и обнародованию Президентом
│     └─ Срок — 14 дней
│
└─ 9. Официальное опубликование и вступление в силу
   ├─ Неопубликованные законы не применяются
   ├─ ФКЗ и ФЗ подлежат официальному опубликованию в течение 7 дней после дня подписания Президентом
   ├─ Официальным опубликованием признается первая полная публикация в:
   │  ├─ «Парламентской газете»;
   │  ├─ «Российской газете»;
   │  ├─ «Собрании законодательства Российской Федерации»; или
   │  └─ первое размещение полного текста на Официальном интернет-портале правовой информации
   └─ По общему правилу закон вступает в силу одновременно на всей территории РФ
      по истечении 10 дней после дня официального опубликования,
      если в самом законе не установлен иной порядок.
```

## 3. Сроки и действия: проверенная таблица

| № | Этап | Действие | ФЗ | ФКЗ | Срок / правило |
|---:|---|---|---|---|---|
| 1 | Внесение | Законопроект и приложения направляются на имя Председателя ГД | Да | Да | Общий срок внесения не установлен |
| 2 | Обязательные материалы | Представляются пояснительная записка, текст, перечень связанных актов, финансово-экономическое обоснование при затратах, а в специальных случаях — дополнительные документы | Да | Да | Одновременно с внесением |
| 3 | Заключение Правительства | Нужно для законопроектов, указанных в ч. 3 ст. 104 Конституции РФ | Да, если применимо | Да, если применимо | Условие внесения таких проектов; общий срок выдачи заключения регулируется специальным законодательством о Правительстве РФ |
| 4 | Регистрация в ГД | Проект регистрируется, получает номер; формируется электронная регистрационная карта | Да | Да | Без отдельного общего срока в Регламенте ГД |
| 5 | Проверка профильным комитетом | Комитет вносит в Совет ГД решение о соответствии проекта требованиям | Да | Да | **14 дней** со дня поступления в профильный комитет; **30 дней**, если применяется процедура с мнением Правового управления по отсутствующему заключению Правительства. Время работы депутатов с избирателями не засчитывается |
| 6 | Мнение Правового управления ГД | По поручению профильного комитета — о соблюдении требований ст. 104 Конституции и п. «д» ч. 1 ст. 105 Регламента ГД | Да, если применимо | Да, если применимо | **14 дней** со дня поступления поручения |
| 7 | Возврат несоответствующего проекта | Профильный комитет возвращает проект инициатору; он не считается внесенным | Да | Да | **14 дней**, либо **30 дней** при процедуре с мнением Правового управления |
| 8 | Совместное ведение: отзывы субъектов РФ | Проект ФЗ направляется региональному парламенту и высшему должностному лицу субъекта РФ | Да, для ФЗ по предметам совместного ведения | Не относится к прямой формулировке ст. 109 Регламента ГД, которая говорит о проектах ФЗ | **30 дней**; Совет ГД вправе сократить срок, но не менее чем до **15 дней**. При поддержке более 2/3 субъектов проект может быть рассмотрен ранее |
| 9 | Подготовка к I чтению | Совет ГД устанавливает сроки отзывов, замечаний и подготовки | Да | Да | Определяется Советом ГД; единого общего максимума нет |
| 10 | Материалы к I чтению | Подготовленный проект и материалы направляются адресатам | Да | Да | Не позднее чем за **3 дня** до рассмотрения на заседании ГД |
| 11 | I чтение | Рассмотрение концепции, актуальности, значения и базового соответствия Конституции | Да | Да | Конкретная дата определяется решениями палаты/Совета ГД |
| 12 | Направление после I чтения | Постановление и текст направляются субъектам законодательной инициативы; для совместного ведения — также региональным парламентам | Да | Да | В течение **5 дней** после принятия/одобрения в I чтении |
| 13 | Поправки после I чтения | ГД устанавливает срок внесения поправок | Да | Да | Как правило, не менее **15 дней**; для проекта ФЗ по предметам совместного ведения — **30 дней**, возможно сокращение, но не менее чем до **15 дней**; срок может быть продлен Советом ГД |
| 14 | Материалы ко II чтению | Законопроект и установленные Регламентом материалы рассылаются адресатам | Да | Да | Как правило, не позднее чем за **7 дней** до II чтения |

## 4. Детали по стадиям

### 4.1. Внесение и предварительная проверка

Право законодательной инициативы принадлежит только субъектам, названным в части 1 статьи 104 Конституции РФ. Гражданин, организация, эксперт или общественное объединение могут подготовить проект или предложение, но для формального внесения в Государственную Думу им нужен один из конституционных субъектов инициативы.

Содержание пакета документов закреплено статьей 105 Регламента ГД. Помимо основного текста, требуются пояснительная записка, перечень взаимосвязанных актов и, при материальных затратах, финансово-экономическое обоснование. Для отдельных категорий установлены дополнительные приложения: например, бюджетные документы, документы по международным договорам, официальные отзывы по некоторым изменениям уголовного и административного законодательства.

Конституционное правило части 3 статьи 104 РФ касается законопроектов о введении или отмене налогов, освобождении от их уплаты, выпуске государственных займов, изменении финансовых обязательств государства и иных проектов, предусматривающих расходы, покрываемые из федерального бюджета: они могут быть внесены только при наличии заключения Правительства РФ.

Профильный комитет в обычном случае вносит вопрос о соответствии проекта требованиям в Совет ГД в течение 14 дней. Если требуется мнение Правового управления из-за отсутствия заключения Правительства, срок составляет 30 дней; само Правовое управление сообщает мнение в течение 14 дней с поступления поручения. Если требования не выполнены, проект возвращается и **не считается внесенным** в Государственную Думу.

### 4.2. Чтения в Государственной Думе

Общее правило Регламента ГД — **три чтения**, если специальный закон или сам Регламент не устанавливает иной порядок.

| Стадия | Содержание | Важные правила |
|---|---|---|
| **Первое чтение** | Концептуальное обсуждение: соответствие основных положений Конституции, актуальность и практическая значимость | ГД может отклонить проект, принять/одобрить его в I чтении с поправками либо при соблюдении условий Регламента принять/одобрить закон сразу, минуя II и III чтения. Ускоренное принятие исключено для проекта по предметам совместного ведения |
| **Поправки** | Предлагаются в виде конкретных изменений, дополнений или исключений | Их вправе вносить субъекты законодательной инициативы. Срок обычно не менее 15 дней; для проектов ФЗ по совместному ведению — 30 дней с возможным сокращением до 15 дней |
| **Второе чтение** | Рассмотрение поправок и текста с их учетом | Комитет готовит предусмотренные Регламентом таблицы. Законопроект, как правило, рассылается не позднее чем за 7 дней до рассмотрения |
| **Третье чтение** | Финальное голосование по законопроекту в целом | Для ФЗ необходимо более половины голосов от общего числа депутатов; для ФКЗ — не менее двух третей |

После первого чтения постановление ГД и законопроект направляются субъектам законодательной инициативы в течение пяти дней. Сам период между чтениями не имеет единого предельного срока: календарь зависит от решения Совета ГД, работы ответственного комитета, сложности проекта, отзывов и поправок.

### 4.3. Совет Федерации и разногласия

Для ФЗ Конституция устанавливает две модели одобрения СФ:

- активное одобрение более чем половиной от общего числа сенаторов РФ;
- одобрение по истечении 14 дней без рассмотрения — **только** для ФЗ, не включенных в перечень статьи 106 Конституции РФ.

Законы по вопросам федерального бюджета, федеральных налогов и сборов, финансового, валютного, кредитного, таможенного регулирования, денежной эмиссии, ратификации и денонсации международных договоров, статуса и защиты государственной границы, войны и мира обязательно рассматриваются Советом Федерации. Для них истечение 14 дней не заменяет решение палаты.

Если СФ отклоняет ФЗ, палаты могут создать согласительную комиссию. После ее работы ГД либо принимает согласованный текст большинством от общего числа депутатов и вновь направляет его в СФ, либо может принять ранее одобренную ею редакцию не менее чем двумя третями голосов. В последнем случае закон направляется Президенту напрямую.

Для ФКЗ требуется одобрение **не менее чем тремя четвертями** от общего числа сенаторов. Конституция не допускает замены этого результата механизмом преодоления отклонения СФ одной Государственной Думой.

### 4.4. Президент, опубликование и сила закона

ФЗ направляется Президенту в течение пяти дней после его принятия в порядке статьи 105 Конституции. Президент в течение 14 дней либо подписывает и обнародует его, либо отклоняет. Если обе палаты повторно одобрят прежнюю редакцию квалифицированным большинством в две трети от общего числа каждой палаты, Президент обязан подписать и обнародовать ФЗ в семидневный срок.

ФКЗ, принятый в конституционно предусмотренном порядке, подлежит подписанию и обнародованию Президентом в течение 14 дней.

Официальное опубликование обязательно: согласно части 3 статьи 15 Конституции РФ неопубликованные законы не применяются. Федеральный закон № 5‑ФЗ требует официального опубликования ФКЗ и ФЗ в течение семи дней после дня подписания Президентом. По общему правилу закон вступает в силу по истечении десяти дней после дня официального опубликования, если сам закон не предусматривает иной срок или порядок.

## 6. Официальная нормативная база

1. **Конституция Российской Федерации:** статьи 15, 76, 104–108.
2. **Регламент Государственной Думы Федерального Собрания РФ:** прежде всего статьи 103–125, а также статьи 127–135³ о повторном рассмотрении ФЗ, отклоненных СФ или Президентом.
3. **Регламент Совета Федерации Федерального Собрания РФ:** порядок регистрации, комитетской подготовки, рассмотрения ФЗ, передачи Президенту и работы при разногласиях.
4. **Федеральный закон от 14 июня 1994 года № 5‑ФЗ** «О порядке опубликования и вступления в силу федеральных конституционных законов, федеральных законов, актов палат Федерального Собрания».
