В теории метода конечных разностей можно выделить следующие основные проблемы:
- каков наилучший выбор сетки
- какое разностное выражение лучше использовать в качестве аналога дифференциального уравнения и граничных условий
- существует ли решение системы разностных уравнений
- сходится ли это решение к решению дифференциальной задачи при сгущении сетки
- какова погрешность разностного решения
- каков лучший способ решения системы разностных уравнений
###### 2 главных этапа при численном решении любой дифференциальной задачи:
1.  получение дискретной аппроксимации дифференциальных уравнений, исследование получающихся при этом разностных уравнений

#### Разностные аналоги операций дифференцирования в методе конечных разностей

*Проблема*: Операции дифференцирования в классической математике производятся над неприрывными функциями
$y(x) \rightarrow y_i$
$dy \rightarrow\ ?$

*Аналог дифференциала второго порядка*

Аналогами для дифференциала 1 порядка сеточной функции является разность первого порядка. *Всего можно определить 3 различных разности 1 порядка:*
1. $Δy_i = Δy_i^{пр} = Δy_i^+ = y_{i+1} - y_i$ - правая разность 
2. $\nabla y_i=Δy_i^{л} = Δy_i^- = y_{i} - y_{i-1}$ - левая разность
3. $δy_i=Δy_i^{центр} = Δy_i^0 = \dfrac{Δy_1+\nabla y_i}{2}$ - центральная разность
---
*Пример 1*

Дана сеточная функция:
$$
y_i=(5,10,17,15,16);\

i=(0,1,2,3,4)
$$
Найдем некоторые разности:
$$
Δy_2=-2;\

\nabla y_3=-2;\

δy_2=2,5
$$
$Δy_4$ не определена для данной сеточной функции. То же самое можно сказать для $\nabla y_0$. Соответственно центральная разность не определена ни для какой границы, ни для левой, ни для правой.

---

*Аналог дифференциала второго порядка*

В качестве аналога можно взять правую разность от правой разности.

$$\dfrac{d^2y}{dx^2} \rightarrow Δ(Δy_i)=Δ(y_{i+1}-y_i)=Δy_{i+1}-Δy_i=y_{i+2}-y_{i+1}-y_{i+1}+y_i=y_{i+1}-2y_{i+1}+y_i$$

Этот аналог требует знать значения на 2 шага вперед, что неудобно. Чтобы этого избежать можно взять *смешанную разность*. Например, правая разность от левой разности.

$$Δ(\nabla y_i)=y_{i+1}-2y_i+y_{i-1}$$

При таком вычислении не нужно знать значения на два шага вперед.
