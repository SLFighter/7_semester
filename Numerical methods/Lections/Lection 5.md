#### Разностные уравнения

 *Линейное разностное уравнение m-ного порядка* - линейное уравнение относительно сеточной функции $y_i=y\left(x_i\right)$ вида $\sum^m_{k-0}a_k\left(i\right)\cdot y\left(i+k\right)=f\left(i\right)$, где $a_k\left(i\right),\ \left(k=0,\ 1,\ ...,\ m\right),\ f\left(i\right)$ - известные сеточные функции, при этом $a_0(i)\neq0;\ a_m(i)\neq0$.

>Пример $m=1$$$a_0(i)\cdot y_i+a_1(i)\cdot y_{i+1}=f(i)$$$a_0\neq0;\ a_1\neq0$. Два неизвестных значения $y\ (m+1)$.
>
>Пример $m=2$$$a_0(i)\cdot y_i+a_1(i)\cdot y_{i+1}+a_2(i)\cdot y_{i+2}=f(i)$$$a_0\neq0;\ a_2\neq0$. Три неизвестных значения $y\ (m+1)$.

Если все коэффициенты $a_k$ не зависят от индекса $i$, то тогда мы будем иметь уравнение с постоянными коэффициентами.

##### Разностное уравнение второго порядка. Задача Коши и краевая задача.
$$\dfrac{d^2y(x)}{dx^2}=f(x)$$$$\dfrac{y_{i+1}-2y_i+y_{i-1}}{h^2}=f(i)\rightarrow\dfrac{1}{h^2}y_{i-1}-\dfrac{2}{h^2}y_i+\dfrac{1}{h^2}y_{i+1}=f(i)$$$$\dfrac{y_{i}-2y_{i+1}+y_{i+2}}{h^2}=f(i)\rightarrow\dfrac{1}{h^2}y_{i}-\dfrac{2}{h^2}y_{i+1}+\dfrac{1}{h^2}y_{i+2}=f(i)$$*Канонический вид разностного уравнения второго порядка:*$$
\begin{equation}
\tag{1}
a(i)\cdot y_{i-1}-c(i)\cdot y_i+b(i)\cdot y_{y+1}=-f(i)
\end{equation}
$$$a(i),\ b(i)\neq0$.$$
\begin{equation}
\tag{2}
y_{i+1}=\dfrac{c(i)\cdot y_i-a(i)\cdot y_{i-1}-f(i)}{b(i)}
\end{equation}
$$
На сетке с $n+1$ узлами будет $n-1$ уравнений. Неизвестных столько же, сколько и уравнений. Необходимо ввести граничные условия.

>Решение любого разностного уравнения по аналогии с дифференциальным уравнением требует задания дополнительных условий. Для уравнения второго порядка потребуется два дополнительных условия. Если оба эти условия задаются в двух соседних точках, то такая задача называется *`задачей Коши`*. Если же условия заданы в двух разных не соседних точках, то тогда такая задача будет называться *`краевой`*.

Условие задачи Коши:
- требуется найти решение уравнения (1) для $i=2,\ 3,\ 4,\ ...,\ N-1$
- при ДУ:
	- $y_0=\mu_0$
	- $y_0=\mu_1$ или же через правую разность: $\Delta y_0=\mu_1-\mu_0=\gamma_0$
В итоге найдем все $y$ для $i=0,\ 1,\ ...,\ N$.

Решение задачи Коши находится непосредственно по формуле (2) с учётом дополнительных условий $\mu_0$ и $\mu_1$.

<u>шаг 1</u>$$y_2=\dfrac{c_1\cdot\mu_1-a_1\cdot\mu_0-f_1}{b_1}$$<u>шаг 2</u>$$y_3=\dfrac{c_2\cdot y_2-a_2\cdot\mu_1-f_2}{b_2}$$<u>шаг 3</u>...

Таким образом формула (2) при решении задачи Коши является рекуррентной формулой. Таким образом значение функции в следующем узле вычисляется с использованием известных значений той же функции в двух предыдущих узлах, начиная с известных значений $y_0$ и $y_1$.$$
\begin{equation}
\tag{2'}
y_{i-1}=\dfrac{c(i)\cdot y_i-b(i)\cdot y_{i+1}-f(i)}{a(i)}
\end{equation}
$$эта формула работает справа налево.
